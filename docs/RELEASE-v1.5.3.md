# EverythingonStart v1.5.3

## 修复

- 修复使用中文输入法时，按 Win 后快速输入，开头几个字母被直接写入搜索框、未参与输入法候选组合的问题。
- 中日韩输入布局下，接管期间缓存原始按键，待搜索框稳定获得焦点后按顺序重放给输入法，不再将缓存拼音作为已提交文本写入搜索框。普通英文布局保持原有行为。
- 保留接管期间的候选空格、退格、回车及拼音分隔符；取消接管时丢弃缓存，前台不是本程序时不重放，避免向其他应用发送缓存按键。
- 保留 v1.5.2 的开始菜单收起、程序置顶及 10%–100% 背景不透明度调整。

## 下载

- `EverythingonStart-v1.5.3-Portable-x64.exe`：绿色单文件版，内置 .NET 与原生 SDK。
- `EverythingonStart-v1.5.3-Setup-x64.exe`：按用户安装，无需管理员权限。
- `EverythingonStart-v1.5.3-source.zip`：对应发行提交的源码。
- `SHA256SUMS.txt`：下载校验。发行包未进行代码签名。

更新前请先从系统托盘完全退出旧实例，再运行绿色版或安装新版；现有设置保留，本地文件检索仍需运行 Everything。

## 验证范围

输入法修复测试版已获用户本机验证可正常使用。自动回归覆盖快速前缀虚拟键重放、候选空格顺序、取消缓存、前台验证及注入失败处理，并回归既有菜单交接、背景模糊、不透明度、拼音搜索、主题、窗口边缘、网页预览和全屏切换。

不同输入法及系统的候选窗行为可能存在差异，不将本次验证视为所有第三方输入法的兼容性保证。

项目原创源码遵循 GPL-3.0-only，已包含第三方来源及许可证。
