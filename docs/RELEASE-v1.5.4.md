# EverythingonStart v1.5.4

## 修复

- 优化连续输入超过 2–4 个字符后搜索响应变慢的问题。拼音展开可能生成上万字符的正则，现在先用汉字条件预筛选拼音分支，避免纯英文文件名执行大型拼音正则；原文、全拼、拼音前缀、首字母与 Everything 高级搜索语法保持支持。
- 输入变化立即使旧查询失效并取消旧请求，避免防抖期间旧结果覆盖新输入。等待中的搜索使用可取消的异步队列，减少大量线程阻塞在原生搜索锁上。

## 改进

- “全部”分类先显示内存索引中的应用、系统设置和直接 Web 搜索入口，再补充 Everything 文件夹与文档结果，不再让应用结果等待两次文件检索。
- 保留 v1.5.3 的中文输入法快速输入接管修复，以及已有分类、排序、网页预览与窗口外观功能。

## 下载

- `EverythingonStart-v1.5.4-Portable-x64.exe`：绿色单文件版，内置 .NET 与原生 SDK。
- `EverythingonStart-v1.5.4-Setup-x64.exe`：按用户安装，无需管理员权限。
- `EverythingonStart-v1.5.4-source.zip`：对应发行提交的源码。
- `SHA256SUMS.txt`：下载校验。发行包未进行代码签名。

更新前请先从系统托盘完全退出旧实例，再运行绿色版或安装新版；现有设置保留，本地文件检索仍需运行 Everything。

## 验证范围

同机、同组输入、隔离默认配置下，文件夹与文档检索合计单次实测：`report` 约 1296 → 172 ms，`jisuanqi` 约 799 → 259 ms，`xiangmuwendang` 约 1180 → 239 ms。隔离 WPF 测试中，输入 `jisuanqi` 后计算器结果首现约 930 → 135 ms。拼音及高级语法回归 74/74 通过；已验证旧查询即时取消、等待请求取消及回滚后的原始行为与文件哈希。

发行提交另通过拼音、Win 键输入交接、Web 网页预览、主题与弹出交接共 213 项回归，并重新检查即时取消、等待请求取消及应用结果提前显示。

这些数据是当前 Everything 索引上的单次测量，不是所有机器或输入的延迟保证。已经进入原生 SDK 的同步搜索不能强制中断，取消用于防止旧结果显示及继续执行过期请求；不同索引规模、中文文件占比与硬件仍会影响响应时间。测试未替换用户正在运行的程序或修改用户设置。
