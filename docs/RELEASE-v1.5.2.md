# EverythingonStart v1.5.2

## 修复

- 修复 v1.5.1 中按 Win 打开开始菜单后直接输入，原生开始菜单不收起、程序面板被压在菜单后面的问题。系统开始菜单会忽略定向消息和失焦通知，并在打开期间拒绝前台切换；现在仅在已确认的开始菜单仍为前台时注入一次 Escape 将其收起，等待菜单离开前台后再激活程序并置顶。Escape 不会落入程序搜索框。

## 改进

- 窗口背景不透明度范围由 75%–100% 扩展为 10%–100%，拖动滑块时主面板与设置窗口实时预览，关闭背景模糊时同样生效。
- 新增“应用不透明度”按钮单独保存；保存全部设置同样生效，取消或关闭设置窗口会恢复已保存的值。文字与按钮不随背景变淡。

## 下载与本机测试

- `EverythingonStart-v1.5.2-Portable-x64.exe`：绿色单文件版，内置 .NET 与原生 SDK。
- `EverythingonStart-v1.5.2-Setup-x64.exe`：按用户安装，无需管理员权限。
- `EverythingonStart-v1.5.2-source.zip`：对应发行提交的源码。
- `SHA256SUMS.txt`：下载校验。发行包未进行代码签名。

先从系统托盘完全退出旧实例，再运行绿色版或安装新版。现有设置保留，不自动更改开机启动项；本地文件检索仍需运行 Everything。

## 验证范围

开始菜单收起方式已在 Windows 11 26H2（开始菜单由 SearchHost 承载）上实测，并经作者本机按 Win 后直接输入的人工验证。回归测试覆盖 Escape 仅在已验证菜单为前台时注入、菜单收起前不激活程序、不透明度预览/保存/取消，以及既有交接、背景模糊、拼音、主题、窗口边缘、网页预览和全屏切换测试。
