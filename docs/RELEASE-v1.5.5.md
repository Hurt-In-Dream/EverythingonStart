# EverythingonStart v1.5.5

## 修复

- 修复 Microsoft Store、Microsoft Rewards 等已注册应用搜索不到的问题。应用索引补充 Windows `AppsFolder` 数据源，收录没有传统开始菜单快捷方式的应用，并在“全部”和“应用”分类中显示。
- 使用应用标识通过 Windows Shell 启动应用，读取原始大小图标并分别缓存，避免不同应用共用默认文件图标。
- 注册应用不执行文件提权、文件所有权获取或打开文件位置操作；保留可复制的 `shell:AppsFolder\应用标识` 启动路径。

## 改进

- 保留已有开始菜单快捷方式、系统快捷入口、拼音与首字母搜索，以及 v1.5.4 的搜索响应优化。
- 新增的注册应用条目来自当前用户的实际数据，不添加尚未安装的应用；Microsoft Rewards 等应用的可用性仍取决于本机安装与注册状态。

## 下载

- `EverythingonStart-v1.5.5-Portable-x64.exe`：绿色单文件版，内置 .NET 与原生 SDK。
- `EverythingonStart-v1.5.5-Setup-x64.exe`：按用户安装，无需管理员权限。
- `EverythingonStart-v1.5.5-source.zip`：对应发行提交的源码。
- `SHA256SUMS.txt`：下载校验。发行包未进行代码签名。

更新前请先从系统托盘完全退出旧实例，再运行绿色版或安装新版；现有设置保留，本地文件检索仍需运行 Everything。

## 验证范围

真实应用回归 46/46 通过，覆盖本机 21 个注册包应用、后台线程索引、并发查询、现有拼音搜索、图标读取与缓存，以及“全部”和“应用”分类最佳匹配。Microsoft Store 与 Microsoft Rewards 均通过实际进程和可见窗口验证启动，仅关闭本次测试新增的窗口，保留已有窗口与用户配置。

发行包另通过单文件自检，验证版本、原生 SDK 加载、图标、内嵌许可证和渲染交接接口。测试未替换用户正在运行的程序，也不执行账户登录或购买操作；这些结果不代表所有 Windows 版本、应用或安装状态的兼容性保证。
