# EverythingonStart v1.5.1

## 修复

- 开始菜单打字接管改为先无激活显示、置顶程序面板，等待 WPF 渲染通道与 DWM 完成后再交接焦点。移除提前发送的全局 Esc，连续输入仍缓冲，不再重复播放明显的滑入动画。
- 完成离屏预热，禁用程序窗口额外的系统显示过渡；单按 Win 直接呼出的 WPF 动画保留，不再固定限制为 60 FPS。
- 修复本机 95% 不透明度下模糊几乎不可见的问题：移除 Accent 的重复染色标志，保留用户不透明度与 Windows 系统透明效果设置。
- 保留 v1.5.0 的拼音/首字母搜索及已有输入干扰修复。

## 下载与本机测试

- `EverythingonStart-v1.5.1-Portable-x64.exe`：推荐先用绿色单文件版测试，内置 .NET 与原生 SDK。
- `EverythingonStart-v1.5.1-Setup-x64.exe`：按用户安装，无需管理员权限。
- `EverythingonStart-v1.5.1-source.zip`：对应发行提交的源码。
- `SHA256SUMS.txt`：下载校验。发行包未进行代码签名。

先从系统托盘完全退出旧实例，再运行绿色版或安装新版，避免旧进程继续处理 Win 键。现有设置保留，不自动更改开机启动项；本地文件检索仍需运行 Everything。

建议检查：按 Win 打开开始菜单后连续输入，观察是否还有“先收起再弹出”或丢字；在设置中开启背景模糊，移动后方窗口检查实时效果。另检查单按 Win 直接呼出及 Win+E/Win+R 组合键。

## 验证范围与兼容性

修复提交已通过 316 项回归检查及额外 10 次交接重复测试，验证自有窗口的真实合成顺序和 95% 遮罩下的实时背景响应；不替代本机真实开始菜单手感、物理键盘、多显示器或游戏安全组件的人工检查。

交接兼容桥集中在 `PopupWindowPreparationService`，依赖 .NET 10 WPF 内部渲染通道接口；接口不可用时取消交接，不提前关闭原生菜单。升级运行时必须重新执行交接测试。发行脚本保留未裁剪的自包含 .NET 运行库。
