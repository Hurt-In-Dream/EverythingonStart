# EverythingonStart v1.5.0

## 新增：拼音与首字母搜索

- 应用、系统设置、本地文件与文件夹支持全拼、拼音前缀与首字母：`jisuanqi` / `jsq` → 计算器，`renwulan` / `rwl` → 任务栏设置，`xiangmuwendang` / `xmwd` → 项目文档。
- 内置离线词典，支持常见多音字、简繁体及中文/数字混合名称；`ü` 可输入 `v`。运行时无需联网或安装 Everything 拼音插件。
- 原文字标题匹配优先于应用/设置的拼音匹配。文件搜索保留分类、附加类型筛选、现有排序和高级语法。
- 内存查询缓存、长度及歧义分词上限，避免无界展开。

## 搜索规则与兼容性

- 推荐连续输入不带声调的全拼或首字母；空格分隔的词保持 AND 匹配。
- 文件搜索中的引号、通配符、路径、`ext:` 等高级语法保持原样，不自动拼音展开。
- 启用区分大小写、全字匹配或正则表达式（含跟随 Everything 配置）时，文件搜索不自动拼音展开；应用/设置仍使用自身匹配规则。
- 文件查询自动展开限制为 48 个字符和 24,000 个正则/查询字符，歧义分词最多 32 条路径；超限输入回退为原生文字查询。覆盖 BMP 中日韩汉字，不承诺词义级多音字消歧或生僻扩展区汉字。
- 已通过 73 项确定性回归及 Everything 1.5 命名管道真实检索（连同回归共 78 项检查）；IPC 的共享查询生成已覆盖，IPC 运行时实测未完成。
- 包含 v1.4.2 的开始菜单输入干扰修复。本版本不代表游戏安全组件兼容性认证。
